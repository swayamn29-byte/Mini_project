# 🏆 SportsHub – Sports Blog and Information Website

> A sports-focused website that brings sports news, trending stories, score information, detailed articles and sports highlights together in one platform.

---

## 📌 About the Project

**SportsHub** is a sports blog and information website developed as a college mini-project using HTML, CSS and JavaScript.

The website provides a centralized platform for sports enthusiasts to explore news, read detailed articles, discover trending stories, view score information and access sports video highlights.

SportsHub covers multiple sports, including Cricket, Football, Basketball, Tennis, Badminton, Hockey, Formula 1 and Volleyball.

The website features a modern dark-themed interface with white text and parrot-green accents, providing a simple and visually appealing browsing experience.

---

## 🎯 Objectives

- Provide sports-related news and information in one platform.
- Display sports news across multiple sports categories.
- Allow users to explore trending sports stories.
- Provide a dedicated page for sports score information.
- Provide access to sports video highlights.
- Allow users to read detailed articles.
- Implement search functionality across website pages.
- Create a user-friendly and visually attractive website using front-end web technologies.

## ⚙️ How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/SportsHub.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Navigate through the website using the navigation bar.

   Alternatively, open the folder in Visual Studio Code and use the Live Server extension.
